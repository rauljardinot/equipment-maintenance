# Equipment Maintenance

Proyecto de prueba para desarrollar módulos de mantenimiento de equipos en Odoo 18.

## Desarrollo

Los módulos personalizados se crearán en la raíz de este repositorio, cada uno en su propia carpeta.
Agrega la ruta de este repositorio al parámetro `addons_path` de tu instalación de Odoo 18 para cargarlos.

## Estado

Repositorio inicial preparado. Aún no contiene módulos.
